# 77 GHz 데이터 생성과 EM 실행

## 현재 요청: 200×200 µm 파일럿 1,000개

300×300 µm 재생성 대신, 200×200 µm의 `serpentine + freeform(v5)`을 먼저 확인한다.
5 µm 격자(40×40), M9 PRI / M8 SEC, 좌우 끝 M9 포트, OUT via 배열을 사용한다.
모든 공정 피처를 2/3로 축소한 GDS가 아니다. 포트 y와 본체 경로는 새 영역 안에서 다시 뽑는다.

```bash
python easy_generate_one_stroke.py --n 1000 --seed 43 --size-um 200 --family serpentine --serpentine-envelope freeform --png --outdir ../batches/serpentine_1000_200x200_seed_43
```

`difftx_*.gds`를 기존 EM 자동화에 입력한다. 먼저 소수 파일의 포트 인식과 설정을 확인한다.
정확한 **77 GHz를 포함하고 최소 150 GHz까지** 넓은 sweep을 요청한다. 시작 주파수와
세부 간격은 기존 흐름과 협의하되, 77 GHz 주변 및 공진·반사 문턱 근처를 충분히 확인한다.
전체 4-port s4p, 실패 ID, 로그, 포트 순서·기준 임피던스, solver·mesh·공정 설정을 함께 보존한다.
고주파 경고와 전체 S 수동성 위반은 설정 검토 후 재계산하며, 경고가 없다는 것만으로 정확성을 확정하지 않는다.

이 batch의 EM 성능은 미검증이다. 아래 300 µm v3 수율을 200 µm v5의 예상 수율로 적용하지 않는다.
현재 비교에는 크기와 생성 분포가 함께 바뀌므로, 성능 차이가 나도 크기만의 영향으로 단정하지 않는다.
장기적으로 크기 탐색을 고려하되 이번 모델 준비는 고정 크기 파일럿이다.

## 생성 방향

기존 one-stroke의 랜덤 경로 분포를 유지하고, 필요한 형상을 골라 대량 생성한 뒤 EM 결과로 선별한다.
현재는 `serpentine` 단독 생성이 가능하며, 성능이 좋았던 소수 사례에 맞춰 생성 범위를 좁히지 않는다.
세 형상을 함께 모으려면 `--family all`을 사용한다.

기존 bounded/expanded Serpentine은 각 권선에서 좌우 횡단 구간을 4개 또는 6개 선택한다.
PRI와 SEC의 선택은 독립적이므로 4/4, 4/6, 6/4, 6/6 조합이 모두 나온다.
외곽 좌표·포트 피치·굴곡 위치가 무작위이며, `aligned / offset / independent`를 고르게 생성한다.
`aligned`도 두 권선의 굴곡과 횡단 구간 수까지 동일하게 고정한다는 뜻은 아니다.

`--serpentine-envelope mixed`를 사용하면 기존 방식과 포트 y 범위 바깥 확장 방식을
샘플별로 50% 확률씩 선택한다. 확장형은 각 권선에서 위·아래·양쪽을 선택하고 본체를
15–60 µm 확장한다. 칩 경계·연결·절연 조건은 유지하며 포트·via writer는 변경하지 않는다.
기존 `bounded`와 신규 `expanded`를 manifest로 구분해 EM 수율을 따로 집계한다.

## 기존 corrected 데이터의 분석 근거

2026-09-09, seed 8 corrected의 serpentine 333개를 분석했다.
기존 EM은 2 GHz 간격이므로 정확한 77 GHz 대신 **76·78 GHz 두 지점 모두**를 기준으로 집계했다.
GDS의 두 금속층 배치와 재생성 경로가 333개 모두 일치함을 확인한 뒤 횡단 구간 수를 분류했다.

| PRI/SEC 횡단 구간 수 | 개수 | 두 지점 모두 S21 통과 | 두 지점 모두 matching 통과 |
|---|---:|---:|---:|
| 4/4 | 76 | 4개, 5.3% | 2개, 2.6% |
| 4/6 | 95 | 10개, 10.5% | 0개, 0.0% |
| 6/4 | 83 | 25개, 30.1% | 4개, 4.8% |
| 6/6 | 79 | 12개, 15.2% | 5개, 6.3% |
| 합계 | 333 | 51개, 15.3% | 11개, 3.3% |

S21 기준은 Sdd21 ≥ −3 dB이다. Matching 기준은 같은 지점에서 S21 기준과 Sdd11·Sdd22 ≤ −10 dB를 동시에 만족하는 것이다. 모두 dB 크기이며 차동 기준 임피던스는 100 Ω이다. 실제 앰프 사이의 매칭이나 연속 대역 전체의 통과를 판정한 것은 아니다.

Matching 통과 11개의 특성을 미통과 322개와 비교하면 다음과 같다.

- PRI 포트 피치 중앙값: 150 µm / 120 µm.
- SEC 포트 피치 중앙값: 160 µm / 120 µm.
- 두 권선의 길이 차이 중앙값: 30 µm / 335 µm. 다만 길이 차이 330–500 µm인 통과 사례도 4개 존재한다.
- PRI/SEC 본체의 투영 겹침 면적 중앙값: 1,300 µm² / 1,312.5 µm². OUT의 M8–M9 landing은 겹침 계산에서 제외했다.
- 배치별 통과: aligned 3/111, offset 6/111, independent 2/111.

통과 사례는 있으나 11개만으로 생성 규칙을 좁힐 근거는 부족하다. 큰 피치·6구간 쪽의 사례가 관찰되었지만 원인을 입증한 것이 아니며, 4/6의 관측 0개가 성공 확률 0을 의미하지도 않는다. 4/4·4/6·6/4·6/6 조합은 모두 유지한다. 새 확장 방식은 분포를 추가하는 별도 실험이지 성능 개선이 입증된 방식이 아니다.

관측 비율이 유지된다고 가정하면 serpentine 1만 개에서 S21 통과 약 1,532개, matching 통과 약 330개가 예상된다. 10만 개면 각각 약 15,315개, 3,303개다. 이는 333개 표본의 비율을 적용한 예상치일 뿐, 정확한 77 GHz 수율이나 수량 보장이 아니다. 먼저 한 batch의 실제 결과와 EM 시간을 확인한다.

## 실행 순서

1. [README](README.md)의 30개 생성 명령으로 GDS 규격과 기존 EM 작업의 호환성을 확인한다.
2. `dataset_meta.json`의 `status=complete`, `verification.json`의 `passed=true`를 확인한다.
3. 소규모 GDS의 EM 경고·수동성·설정 호환성을 먼저 확인하고 첫 1만 개로 확대한다. 10만 개 확장은 첫 batch의 소요시간·오류·실제 수율을 확인한 뒤 진행한다.
4. 각 batch의 manifest를 기준으로 누락·중복 s4p를 확인하고 분석한다. 성공·실패 결과 모두 보존한다.

같은 seed·family로 batch를 나눌 때 `--start-index`를 0, 10000, 20000처럼 증가시킨다.
ID가 서로 겹치는 다른 seed/family의 결과는 별도 디렉터리에 둔다.
생성기는 GDS만 만들며 ADS/Momentum 실행 명령은 포함하지 않는다.

## EM 조건

### 77 GHz 주경로

- 새 GDS와 기존 corrected 1,000개에 **정확한 77 GHz**를 포함한다.
- 가능하면 74–80 GHz를 0.5 GHz 간격으로 계산한다. 첫 생성 목표는 77 GHz 한 지점이며 주변 대역은 별도 확인용이다.
- 기존 RF 결과와 비교하려면 동일 공정·기판·금속·포트 설정을 유지한다. Microwave로 바꾼 결과는 별도 solver 버전으로 보존한다.
- 최종 판단에 쓸 대표 사례는 mesh 수렴과 solver 차이를 별도 확인한다. 생성기 검사는 EM 정확성 검사가 아니다.
- 대역폭이 목적이면 74–80 GHz만으로 끝내지 않는다. 양쪽 반사 문턱이 실제로 교차하는 주파수까지 sweep하고, 교차점 주변을 세분화한다.

### 성능과 수치 품질의 구분

- dB S21은 높을수록 좋다. `IL = −20 log10(|Sdd21|)`로 정의하면 IL은 낮을수록 좋다.
- dB S11·S22는 더 음수일수록 반사가 작다. `RL = −20 log10(|Sdd11 또는 Sdd22|)`로 정의하면 RL은 높을수록 좋다.
- 타깃에서의 전달 성능, sweep의 S21 peak와 타깃의 거리, 타깃을 포함하는 연속 반사 대역을 각각 기록한다. 반드시 peak가 타깃과 정확히 같아야 한다는 보편 조건은 두지 않는다.
- RL 대역은 Sdd11·Sdd22 ≤ −10 dB를 동시에 만족하는 타깃 주변 연결 구간이다. 전달 조건까지 포함하는 joint 대역은 여기에 Sdd21 ≥ −3 dB를 추가한다.
- 떨어진 통과 구간을 이어서 대역폭으로 세지 않는다. 샘플 사이 문턱은 추정치이며, sweep 끝에 닿으면 대역폭 하한만 확인한 것이다.
- 실수 50 Ω 기준의 전체 S행렬은 `sigma_max(S) ≤ 1`이어야 수동성을 만족한다. 분석 코드는 1e−6 수치 허용오차를 사용한다. 차동 블록만 정상이어도 전체 4-port가 정상이라는 뜻은 아니다.
- 로그에 `S-parameter data show unphysical behavior`가 있거나 전체 S가 수동성을 위반하면, 포트·via 모델·mesh·solver compression·calibration 설정을 검토한다. 원인이 확인되기 전 강제 수동성 보정으로 학습 라벨을 만들지 않는다.

첫 모델의 조건은 주파수 숫자만이 아니라 **77 GHz의 복소 4-port S행렬**이다.
한 주파수의 S행렬만으로 대역폭이나 peak 위치까지 지정할 수는 없다.
처음에는 주변 sweep을 평가용으로 사용하고, 필요하면 이후 여러 주파수의 S 또는 별도 대역 조건으로 확장한다.
현재 고정 77 GHz 모델의 완료 조건에 다중 주파수 일반화를 섞지 않는다.

### 100–200 GHz 탐색

- 우선 세 형상에서 각각 10개씩 대표 사례를 선정한다. 77 GHz 주변 우수 사례, 100 GHz 우수 사례, 낮은 성능 사례를 포함한다.
- 동일 GDS를 RF/Microwave로 비교하며, 기존 대역과 겹치는 주파수도 포함한다. 구체적인 30개 ID는 별도로 확정한다.
- 이미 확장 sweep이 있다면 먼저 로그와 전체 S 수동성을 확인한다. 비물리적 응답이 있으면 대표 실패 사례로 설정·mesh를 교차검증하고 나서 확대한다.
- 140 GHz를 포함하고, 관심 응답이 확인되면 그 주변 주파수 격자를 세분화한다.
- 100 GHz에서 성능이 좋다는 사실만으로 140 GHz 성능을 보장하지 않는다.

RF는 준정적 방식, Microwave는 full-wave 방식이다. 동일 구조의 비교로 차이를 확인한다. [Keysight 공식 설명](https://www.keysight.com/zz/en/lib/resources/technical-specifications/momentum-simulator-engine-2061985.html)

## 반환 파일과 설정

- 원본 GDS 디렉터리의 `manifest.csv`, `dataset_meta.json`, `verification.json`을 보존한다.
- 샘플별 **전체 복소 4-port s4p**를 반환한다. S21 크기나 통과한 샘플만 반환하지 않는다.
- `difftx_00000.gds → difftx_00000.s4p`를 권장한다. 기존 작업의 `ostk_00000.s4p`도 숫자 ID가 동일하면 분석할 수 있다.
- EM이 batch마다 0번부터 다시 번호를 매기면 원본 전역 ID와의 대응표가 필요하다. 대응 없이 파일을 합치지 않는다.
- 실패한 ID와 원인, 샘플별 로그, solver 모드·버전, 주파수 목록, 공정/기판 설정 버전, mesh·수렴 설정을 함께 반환한다.
- 포트 순서는 `[IN_P, IN_N, OUT_P, OUT_N]`이며, single-ended 포트별 50 Ω 기준과 기준면/포트 설정을 명시한다. 다른 순서라면 대응표와 함께 반환하고 분석 전에 변환한다.
- 첫 batch의 실제 생성·EM 소요시간과 실패 개수를 알려주면 다음 생성 규모를 정할 수 있다.

모델의 최종 입출력은 `77 GHz 복소 4-port S → 두 금속층 layout`이다. S21·matching 선별 결과는 데이터 분포를 보는 보조 지표이며, 학습에는 정상적인 낮은 성능 데이터도 사용한다.
